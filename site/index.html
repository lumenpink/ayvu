📖 Guia Rápido de Marcação (Markup)

O Ayvu aceita scripts conversacionais intuitivos. Cada linha representa um balão de fala.

Elemento Sintaxe Efeito Visual
Fala Normal Nome: texto Balão elíptico com rabo direcionado à boca.
Expressão Explícita Nome (happy): texto Altera os olhos, boca e orelhas do avatar.
Pensamento Nome (thinking): texto ou oO texto Balão em formato de nuvem com círculos.
Grito / Alerta Nome: TEXTO EM MAIÚSCULAS! Balão pontiagudo com raio de explosão.
Novo Painel --- Fecha o painel atual e inicia o próximo.
Onomatopeia [POW!], [CRASH!], [BOOM!] Estrela de impacto de 16 pontas com tipografia retrô.
Stickers [heart], [sweat], [shock], [idea] Ícones flutuantes manga/comic sobre os personagens.
Layout [layout: grid], [layout: vertical] Formata em grade 2x2 para redes ou vertical para mobile.
Largura do Quadro [narrow], [standard], [wide], [panoramic] Ajusta a largura do painel (210px, 280px, 360px, 450px ou [width: 320]).
Cenário por Quadro [backdrop: hu_fachada], [backdrop: ru], [backdrop: hall_ccs], [backdrop: sala_de_aula], [backdrop: bu_ufsc] Alterna cenários vetoriais da UFSC (HU, RU Bandejão, Hall CCS, Salas, BU) ou clássicos por painel.
Objetos de Cena (Props) [prop: cafe], [prop: cafe @ Dan], [props: livro, laptop] Adiciona objetos em nanquim autêntico (café, livro, laptop, erlenmeyer, giz, estetoscópio, microfone) no chão ou nas mãos do personagem.

🔌 Integração via API REST

Exemplo de chamada direta para o daemon local (ayvu serve) ou endpoint remoto:

curl -X POST http://localhost:3100/render \ -H "Content-Type: application/json" \ -d '{ "text": "Tiki (happy): Olá!\n---\nJordan: Funciona!", "title": "Minha Tirinha", "layout": "grid" }' > tirinha.svg

Como Embutir no Obsidian

Basta colar o link de renderização com a diretiva de imagem markdown:

![Tirinha Ayvu](http://localhost:3100/render?text=Tiki+(happy):+Oi!%0A---%0AJordan:+E+ai!&title=Obsidian+Sync&layout=grid)
